🎯 Objective

Setelah UAT passed (target 6 Agustus 2026), deploy production ke server fisik milik Pion Tech Solution, arahkan DNS piontechsolution.com, aktifkan SSL. Go-live 10 Agustus 2026.

📋 Server Preparation (Server Pion Tech)
# Ubuntu 22.04 — install stack
sudo apt update && sudo apt install -y nginx mysql-server \
  php8.3-fpm php8.3-mysql php8.3-mbstring php8.3-xml \
  php8.3-curl php8.3-zip php8.3-gd php8.3-intl \
  composer git certbot python3-certbot-nginx

# MySQL: buat database + user production
CREATE DATABASE piontech_billing;
CREATE USER 'piontech'@'localhost' IDENTIFIED BY '<strong-password>';
GRANT ALL ON piontech_billing.* TO 'piontech'@'localhost';
📋 Deploy Steps
# 1. Clone & install
git clone <repo> /var/www/piontech-billing
cd /var/www/piontech-billing
composer install --optimize-autoloader --no-dev

# 2. Env production
cp .env.example .env
# APP_ENV=production, APP_DEBUG=false
# APP_URL=https://piontechsolution.com
# DB credentials production
php artisan key:generate

# 3. Migrate + import data production
php artisan migrate --force
# Import data pelanggan REAL via fitur import (TASK-11)
# atau: mysqldump dari VPS dev → restore (jika data UAT dipakai)

# 4. Optimize
php artisan storage:link
php artisan config:cache && php artisan route:cache && php artisan view:cache
php artisan filament:optimize

# 5. Permissions
chown -R www-data:www-data storage bootstrap/cache

# 6. Nginx vhost + SSL
# server_name piontechsolution.com;
# root /var/www/piontech-billing/public;
sudo certbot --nginx -d piontechsolution.com

# 7. DNS: A record piontechsolution.com → IP publik statis server Pion Tech

# 8. Cron untuk scheduler (backup, dsb.)
* * * * * cd /var/www/piontech-billing && php artisan schedule:run
📋 Backup & Rollback Plan
  • Backup otomatis: mysqldump harian via scheduler → simpan 30 hari (spatie/laravel-backup opsional)
  • Rollback: VPS Albiruni tetap aktif 30 hari pasca go-live sebagai fallback — jika server klien bermasalah, DNS bisa diarahkan kembali sementara
  • Monitoring sederhana: uptime check via cron curl + notifikasi (opsional UptimeRobot free)
