TASK-14 — Testing Layer 2 — Feature Tests Konsolidasi

End-to-end per-fitur via Livewire: alur lengkap tiap role tanpa browser
Module: Quality Assurance Estimasi: 4 jam Prioritas: P1
📌 Dependencies (kerjakan setelah task berikut selesai)
TASK-13
🎯 Objective

Feature test menguji alur lengkap di level HTTP/Livewire — lebih cepat dari browser test, mengcover integrasi antar komponen. Fokus: 3 user journey utama per role.

📋 User Journeys yang Harus Teruji
JourneyLangkah
J1: Admin — siklus tagihan penuhLogin admin → buat pelanggan baru → pelanggan muncul di tagihan bulan ini → catat pembayaran tunai via petugas → status lunas → dashboard terupdate → tandai pelanggan lain ISOLIR → muncul di laporan tunggakan
J2: Petugas — hari kerja lapanganLogin petugas → lihat tagihan jatuh tempo hari ini (hanya cluster sendiri) → catat pembayaran tunai → uang di petugas bertambah → catat titip 500rb → sisa berkurang → TIDAK bisa lihat pelanggan cluster lain → TIDAK ada opsi transfer
J3: Transfer & rekonsiliasiAdmin catat pembayaran transfer → officer_id null → dashboard 'via transfer' bertambah → 'uang di petugas' TIDAK berubah → laporan rekap memisahkan tunai vs transfer
📋 Implementation Pattern
// tests/Feature/Journeys/AdminBillingCycleTest.php
it('completes full billing cycle as admin', function () {
    $admin = adminUser();
    $this->actingAs($admin);

    // Step 1: create pelanggan
    livewire(CreateCustomer::class)
        ->fillForm([...])->call('create')
        ->assertHasNoFormErrors();
    $p = Customer::latest()->first();

    // Step 2: muncul di tagihan
    expect(Customer::billable()->pluck('id'))->toContain($p->id);

    // Step 3: catat pembayaran
    livewire(CreateTransaction::class)
        ->fillForm(['customer_id'=>$p->id, ...])
        ->call('create');
    expect($p->transaksi()->first()->status)->toBe('paid');

    // Step 4: dashboard consistent
    $r = BillingService::monthlySummary(now());
    expect($r['total_terkumpul'])->toBeGreaterThan(0);
    // ... lanjut step ISOLIR & laporan
});
✅ Acceptance Criteria — Definition of Done
  • 3 journey test lengkap dan hijau
  • J2 memverifikasi isolasi cluster DAN absennya opsi transfer untuk petugas
  • J3 memverifikasi transfer tidak mengubah uang di petugas
  • Semua assertion angka menggunakan nilai eksplisit (bukan hanya toBeGreaterThan bila bisa dihitung)
  • Suite feature selesai < 2 menit
