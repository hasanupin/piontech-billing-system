TASK-01 — Setup Project & Tech Stack (Docker)

Laravel terbaru + Filament v5 + Tailwind, dijalankan via Docker Compose untuk local development & testing yang konsisten
Module: Infrastructure Estimasi: 2-3 jam Prioritas: P0 — Blocker
📌 Dependencies
Tidak ada — task pertama yang dikerjakan
🎯 Objective

Menyiapkan project Laravel (versi terbaru stable) dengan Filament v5 sebagai admin panel dan Tailwind CSS untuk styling, seluruhnya berjalan di dalam Docker menggunakan docker-compose. Semua checking dan testing dilakukan lewat container lokal ini — bukan langsung di mesin host — supaya environment konsisten untuk siapa pun (developer atau AI agent) yang menjalankan project ini.

ℹ️ Docker Compose dipakai KHUSUS untuk local development & testing. Deployment production tetap ke server fisik milik Pion Tech Solution (lihat TASK-16) — bukan dalam container.
📋 Prasyarat di Mesin Host
  • Docker Desktop (atau Docker Engine + Docker Compose di Linux) sudah terinstall dan berjalan
  • Git terinstall
  • Port host 8002 (app), 3309 (MySQL), 6382 (Redis) tidak dipakai service lain
📋 Langkah 1 — Jalankan Project via Docker Compose

Project sudah menyertakan Dockerfile (php:8.4-apache) dan docker-compose.yml custom — cukup build & jalankan, tidak perlu PHP/Composer di mesin host.

git clone <repo> piontech-billing
cd piontech-billing
docker-compose up -d --build
✅ docker-compose.yml mendefinisikan 3 service: app (Laravel + Apache, host port 8002), db (MySQL 8, host port 3309), redis (host port 6382).
📋 Langkah 2 — Menjalankan Command di dalam Container

Semua command Artisan/Composer/NPM dijalankan LEWAT container app:

docker-compose exec app php artisan --version
docker-compose exec app composer --version
docker-compose exec app npm --version
ℹ️ Host memakai PHP 8.5, jadi php artisan juga bisa dijalankan langsung di host (terhubung ke MySQL/Redis docker via port 3309/6382). Untuk konsistensi, contoh di bawah memakai docker-compose exec app.
📋 Langkah 3 — Install Filament v5 (di dalam container)
docker-compose exec app composer require filament/filament:"^5.0" -W
docker-compose exec app php artisan filament:install --panels
# Panel ID: admin

# Buat user admin pertama untuk login
docker-compose exec app php artisan make:filament-user
ℹ️ Filament v5 sudah menggunakan Tailwind CSS secara built-in untuk seluruh admin panel — tidak perlu setup Tailwind terpisah untuk halaman admin. Tailwind config Filament otomatis ter-compile saat build asset.
📋 Langkah 4 — Package Pendukung
# RBAC pakai enum Role + ScopeService (tanpa spatie/laravel-permission)
docker-compose exec app composer require maatwebsite/excel
docker-compose exec app composer require barryvdh/laravel-dompdf

# Testing: PHPUnit sudah bawaan Laravel — tidak perlu instalasi tambahan
ℹ️ Tanpa spatie/laravel-permission: role diwakili App\Enums\Role (backed enum) + semua scoping terpusat di App\Services\ScopeService. Lihat CLAUDE.md bagian "Roles & Scoping".
📋 Langkah 5 — Build Asset Tailwind (Admin Panel)
docker-compose exec app npm install
docker-compose exec app npm run build

# Untuk development dengan hot-reload:
docker-compose exec app npm run dev
⚠️ Jika mengubah tema/warna Filament (branding biru #1A4F8A sesuai proposal), edit resources/css/filament/admin/theme.css lalu jalankan ulang npm run build.
📋 Langkah 6 — Konfigurasi .env
APP_NAME="PionTech Billing"
APP_ENV=local
APP_URL=http://localhost
APP_TIMEZONE=Asia/Jakarta
APP_LOCALE=id

# Di dalam container app, DB_HOST=db & DB_PORT=3306 di-override
# oleh docker-compose.yml. Nilai di bawah dipakai saat `php artisan`
# dijalankan dari host (akses MySQL docker via port 3309).
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3309
DB_DATABASE=piontech_billing
DB_USERNAME=laravel_user
DB_PASSWORD=laravel_password

FILESYSTEM_DISK=public
⚠️ Timezone WAJIB Asia/Jakarta dan locale id — seluruh timestamp tagihan & setoran mengikuti WIB, dan format tanggal Filament tampil dalam Bahasa Indonesia.
📋 Langkah 7 — Migrate & Git Init
docker-compose exec app php artisan migrate

git init
git add .
git commit -m "chore: initial Laravel + Filament v5 + Docker setup (TASK-01)"
🧪 Testing Requirement
  • Container check: docker-compose ps → semua service (app, db, redis) status "Up"
  • Smoke test: buka http://localhost:8002 → root redirect ke /admin
  • Filament test: buka http://localhost:8002/admin → halaman login Filament muncul dengan styling Tailwind rapi
  • Login test: user admin yang dibuat di Langkah 3 bisa login
  • PHPUnit test: docker-compose exec app php artisan test → default test pass
  • Timezone check: docker-compose exec app php artisan tinker → now() → pastikan offset +07:00
✅ Acceptance Criteria — Definition of Done
  • Project berjalan sepenuhnya via Docker Compose — tidak bergantung pada PHP/Composer di host
  • docker-compose up -d berhasil, docker-compose ps menunjukkan semua service Up
  • Laravel versi terbaru stable terpasang (cek via docker-compose exec app php artisan --version)
  • Filament v5 terpasang, panel /admin bisa diakses dan menampilkan Tailwind styling dengan benar
  • User admin pertama berhasil dibuat dan bisa login
  • Package pendukung (maatwebsite/excel, barryvdh/laravel-dompdf) terpasang tanpa conflict; RBAC pakai enum Role + ScopeService (tanpa spatie)
  • docker-compose exec app php artisan test berjalan hijau
  • .env terkonfigurasi: timezone Asia/Jakarta, locale id, koneksi MySQL docker
  • Git repository terinisialisasi, .env TIDAK ter-commit (cek .gitignore)
