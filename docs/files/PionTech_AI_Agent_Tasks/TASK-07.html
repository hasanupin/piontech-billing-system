TASK-07 — Pelanggan Resource + Status ISOLIR

CRUD pelanggan lengkap dengan quick action Tandai ISOLIR / Pulihkan Aktif
Module: Core Feature Estimasi: 4-5 jam Prioritas: P0
📌 Dependencies (kerjakan setelah task berikut selesai)
TASK-05TASK-06
🎯 Objective

Resource inti sistem. Mencakup: form pelanggan lengkap, quick action perubahan status (AKTIF ↔ ISOLIR, OFF), filter jatuh tempo, dan tampilan yang setara dengan sheet Excel klien.

📋 Form Schema
Section::make('Identitas')->schema([
    TextInput::make('name')->required(),
    TextInput::make('full_name'),
    TextInput::make('whatsapp_number')->tel()->prefix('+62')
        ->helperText('Tanpa 0 di depan, contoh: 81234567890'),
]),
Section::make('Penugasan & Paket')->schema([
    Select::make('cluster_id')->relationship('clusters','name')
        ->searchable()->required()
        ->helperText('ACUAN penugasan petugas'),
    Select::make('package_id')->relationship('paket','name')
        ->nullable()->helperText('Referensi harga saja'),
    TextInput::make('billing_day')->numeric()
        ->minValue(1)->maxValue(31)->required(),
]),
Section::make('Lokasi (Referensi)')->schema([
    TextInput::make('address')->helperText('Nama kampung — referensi saja'),
    TextInput::make('maps_url')->url(),
    FileUpload::make('house_photo_url')->image()->directory('foto-rumah'),
]),
Section::make('Status')->schema([
    Select::make('status')->options([
        'active'=>'Aktif','suspended'=>'ISOLIR','terminated'=>'OFF'])->required(),
    DatePicker::make('registered_at')->required(),
]),
📋 Quick Actions — ISOLIR Logic
Tables\Actions\Action::make('suspended')
    ->label('Tandai ISOLIR')->color('warning')
    ->icon('heroicon-o-lock-closed')
    ->visible(fn($r) => $r->status === 'active'
        && auth()->user()->isRole(Role::Admin))
    ->requiresConfirmation()
    ->action(fn(Pelanggan $r) => $r->update([
        'status' => 'suspended',
        'suspended_at' => now()->toDateString()])),

Tables\Actions\Action::make('pulihkan')
    ->label('Pulihkan Aktif')->color('success')
    ->visible(fn($r) => $r->status === 'suspended'
        && auth()->user()->isRole(Role::Admin))
    ->action(fn(Pelanggan $r) => $r->update([
        'status' => 'active', 'suspended_at' => null])),
⚠️ ISOLIR = jatuh tempo belum bayar, blokir sementara. Pelanggan ISOLIR TETAP muncul di daftar tagihan. Hanya admin yang bisa ubah status.

it('admin can mark pelanggan as isolir with suspended_at', function () {
    $p = Customer::factory()->create(['status'=>'active']);
    $this->actingAs(adminUser());
    // Call the action via Livewire
    livewire(CustomerResource\Pages\ListPelanggans::class)
        ->callTableAction('suspended', $p);
    expect($p->fresh())
        ->status->toBe('suspended')
        ->suspended_at->not->toBeNull();
});
