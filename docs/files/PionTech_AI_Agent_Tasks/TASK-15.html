TASK-15 — Testing Layer 3 — E2E via Chrome (Claude Code)

Browser testing nyata via Claude in Chrome: visual, interaksi JS, alur multi-role
Module: Quality Assurance Estimasi: 3-4 jam Prioritas: P2
📌 Dependencies (kerjakan setelah task berikut selesai)
TASK-14
🎯 Objective

Layer terakhir: test di browser sungguhan menggunakan Claude Code + Claude in Chrome extension. Berbeda dari feature test, layer ini memverifikasi hal yang hanya terlihat di browser: reaktivitas Livewire (pre-fill nominal), hidden/show field, badge warna, dan alur klik nyata.

ℹ️ Alternatif tanpa Claude in Chrome: Laravel Dusk. Namun instruksi di bawah dioptimalkan untuk Claude Code mengoperasikan Chrome langsung.
📋 Persiapan Environment
# 1. Pastikan app jalan di URL yang bisa diakses Chrome
docker-compose exec app php artisan serve (atau langsung akses http://localhost karena sudah expose port)
# atau gunakan URL dev VPS: https://piontech.albiruni.dev

# 2. Seed data test yang deterministik
docker-compose exec app php artisan migrate:fresh --seed --env=testing

# 3. Kredensial test (dari seeder):
#    ceo@test.local / password    (super_admin)
#    admin@test.local / password  (admin)
#    budi@test.local / password   (field_officer, Cluster A)
📋 Skenario E2E — Checklist untuk Claude in Chrome
#SkenarioVerifikasi Visual/Interaksi
E1Login 3 role bergantianMenu sidebar berbeda per role: petugas TIDAK melihat Master Data & User
E2Admin buat pelangganIsi form 4 section, upload foto, submit → muncul di tabel dengan badge hijau AKTIF
E3Pre-fill reaktif transaksiPilih pelanggan → field nominal terisi otomatis dari paket → edit manual ke angka lain → submit sukses dengan angka override
E4Toggle metode transferPilih 'Transfer' → field petugas MENGHILANG dari form (reaktivitas Livewire)
E5Login petugas — opsi transferDropdown metode HANYA berisi 'Tunai'
E6Quick action ISOLIRKlik 'Tandai ISOLIR' → modal konfirmasi → confirm → badge berubah kuning ISOLIR
E7Info panel setoran liveForm setoran: pilih petugas → placeholder 'Sisa Belum Disetor' menampilkan angka; ganti periode → angka berubah
E8Link WA & MapsKlik nomor WA di tabel → tab baru wa.me; klik Maps → tab baru Google Maps
E9Dashboard rekonsiliasiCatat 2 transaksi tunai (300rb) + 1 transfer (110rb) + 1 titip (100rb) → verifikasi stat: terkumpul 410rb, via transfer 110rb, di petugas 200rb
E10Download laporanHalaman laporan → pilih periode → klik Download PDF → file terunduh dan berisi angka sama dengan dashboard
📋 Format Laporan Hasil E2E
# Setelah semua skenario, Claude Code membuat file:
# tests/e2e/E2E_REPORT_YYYY-MM-DD.md berisi:
- Tanggal & environment (URL, browser)
- Tabel hasil: E1–E10 PASS/FAIL + screenshot path
- Bug yang ditemukan dengan langkah reproduksi
- Rekomendasi perbaikan
✅ Acceptance Criteria — Definition of Done
  • Semua 10 skenario E1–E10 dijalankan di Chrome nyata
  • Setiap skenario ada screenshot bukti
  • E9 (rekonsiliasi angka) menggunakan nilai eksplisit dan cocok
  • Laporan E2E_REPORT tersimpan di repo
  • Bug (jika ada) tercatat dengan langkah reproduksi
