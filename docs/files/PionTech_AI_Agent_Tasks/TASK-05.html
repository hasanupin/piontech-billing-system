CRUD paket internet — harga sebagai referensi/pre-fill, bukan constraint
Module: Master Data Estimasi: 1-2 jam Prioritas: P1

🎯 Objective

Filament Resource untuk master paket. Ingat: paket hanya label referensi — default_price dipakai untuk pre-fill form transaksi tapi admin bebas override.

📋 Spesifikasi Form & Table
// Form
TextInput::make('name')->required()
    ->placeholder('Contoh: Paket 110'),
TextInput::make('default_price')->numeric()->prefix('Rp')->required()
    ->helperText('Harga referensi — bisa dioverride saat input transaksi'),
TextInput::make('speed_mbps')->numeric()->nullable(),
Textarea::make('description'),
Toggle::make('is_active')->default(true),

// Table
TextColumn::make('name')->searchable()->sortable(),
TextColumn::make('default_price')->money('IDR')->sortable(),
TextColumn::make('pelanggan_count')->counts('customers')
    ->label('Dipakai oleh'),
IconColumn::make('is_active')->boolean(),
🧪 Testing — Feature Test (PHPUnit + Livewire)
// Livewire test: Livewire::test(...)

it('admin can create paket', function () {
    $this->actingAs(User::factory()->create(['role' => Role::Admin]));
    livewire(PackageResource\Pages\CreatePackage::class)
        ->fillForm(['name'=>'Paket 110','default_price'=>110000])
        ->call('create')->assertHasNoFormErrors();
    expect(Package::where('name','Paket 110')->exists())->toBeTrue();
});

it('petugas cannot access paket resource', function () {
    $this->actingAs(User::factory()->create(['role' => Role::FieldOfficer]));
    $this->get(PackageResource::getUrl('index'))->assertForbidden();
});
✅ Acceptance Criteria — Definition of Done
  • Admin bisa CRUD paket via Filament
  • super_admin hanya view (tidak bisa create/edit)
  • field_officer tidak melihat menu paket sama sekali
  • Kolom 'Dipakai oleh' menampilkan jumlah pelanggan per paket
  • Feature test hijau (min 3 cases: create admin, forbidden petugas, view ceo)
