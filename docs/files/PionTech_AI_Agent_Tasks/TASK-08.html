TASK-08 — Transaksi Resource (Tunai + Transfer)

Input pembayaran dengan pre-fill harga editable, metode tunai/transfer, auto-status
Module: Core Feature Estimasi: 4-5 jam Prioritas: P0
📌 Dependencies (kerjakan setelah task berikut selesai)
TASK-07
🎯 Objective

Resource pencatatan pembayaran — pengganti kolom BAYAR di Excel. Dua alur: tunai via petugas (masuk hitungan uang petugas) dan transfer langsung (settled, tanpa petugas).

📋 Form dengan Logic Reaktif
Select::make('customer_id')
    ->relationship('customers','name',
        fn($q)=>$q->billable())         // hanya AKTIF + ISOLIR
    ->searchable()->required()->live()
    ->afterStateUpdated(function($state,Set $set) {
        // Pre-fill nominal dari paket — EDITABLE
        $p = Customer::find($state);
        $set('billed_amount', $p?->paket?->default_price);
    }),

Select::make('payment_method')->live()
    ->options(fn() => auth()->user()->isRole(Role::Admin)
        ? ['cash'=>'Tunai (via Petugas)','transfer'=>'Transfer Langsung']
        : ['cash'=>'Tunai'])          // petugas tidak lihat transfer
    ->default('cash')->required(),

Select::make('officer_id')
    ->relationship('petugas','name', fn($q)=>$q->role('field_officer'))
    ->hidden(fn(Get $get)=>$get('payment_method')==='transfer')
    ->default(fn()=>auth()->user()->isRole(Role::FieldOfficer)
        ? auth()->id() : null),

DatePicker::make('period')->displayFormat('F Y')
    ->default(now()->startOfMonth())->required(),

TextInput::make('billed_amount')->numeric()->prefix('Rp')->required()
    ->helperText('Pre-fill dari paket — BISA DIEDIT'),
TextInput::make('paid_amount')->numeric()->prefix('Rp')->required(),
DateTimePicker::make('paid_at')->default(now())->required(),
