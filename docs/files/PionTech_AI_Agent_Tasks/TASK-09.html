TASK-09 — Setoran Petugas (Titip) Resource

Pencatatan titip parsial + info panel sisa belum disetor real-time
Module: Core Feature Estimasi: 3 jam Prioritas: P0
📌 Dependencies (kerjakan setelah task berikut selesai)
TASK-08
🎯 Objective

Pengganti digital dari TITIP 1–4 + KEKURANGAN SETOR di header Excel. Petugas inisiasi setoran, admin konfirmasi. Form menampilkan sisa yang belum disetor secara real-time.

📋 Form dengan Info Panel
Select::make('officer_id')
    ->relationship('petugas','name',fn($q)=>$q->role('field_officer'))
    ->default(fn()=>auth()->user()->isRole(Role::FieldOfficer)
        ? auth()->id() : null)
    ->disabled(fn()=>auth()->user()->isRole(Role::FieldOfficer))
    ->live()->required(),

DatePicker::make('period')->displayFormat('F Y')
    ->default(now()->startOfMonth())->live()->required(),

// ⭐ INFO PANEL — sisa belum disetor
Placeholder::make('info_sisa')
    ->label('💰 Sisa Belum Disetor Periode Ini')
    ->content(function(Get $get) {
        if (!$get('officer_id')) return '—';
        $sisa = BillingService::officerRemainingBalance(
            $get('officer_id'), Carbon::parse($get('period')));
        return 'Rp '.number_format($sisa,0,',','.');
    }),

TextInput::make('amount')->numeric()->prefix('Rp')->required(),
Select::make('received_by')
    ->relationship('penerima','name',fn($q)=>$q->role('admin'))
    ->required(),
DateTimePicker::make('deposited_at')->default(now())->required(),

🧪 Testing — Feature Tests
it('calculates sisa correctly after multiple titip', function () {
    $petugas = petugasFactory();
    // Tunai terkumpul: 3.000.000
    Transaction::factory()->count(3)->create([
        'officer_id'=>$petugas->id, 'payment_method'=>'cash',
        'paid_amount'=>1000000, 'period'=>now()->startOfMonth()]);
    // TITIP 1: 1jt, TITIP 2: 500rb
    OfficerDeposit::factory()->create(['officer_id'=>$petugas->id,
        'amount'=>1000000,'period'=>now()->startOfMonth()]);
    OfficerDeposit::factory()->create(['officer_id'=>$petugas->id,
        'amount'=>500000,'period'=>now()->startOfMonth()]);
    // Sisa harus 1.500.000
    expect(BillingService::officerRemainingBalance($petugas->id, now()))
        ->toBe(1500000.0);
});
