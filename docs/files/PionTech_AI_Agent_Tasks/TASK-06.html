TASK-06 — Master Cluster Resource

CRUD cluster — acuan penugasan pelanggan ke petugas. Fitur pindah petugas PIC.
Module: Master Data Estimasi: 2 jam Prioritas: P1

🎯 Objective

Cluster adalah acuan resmi penugasan (bukan alamat). Satu cluster = satu petugas PIC. Fitur kunci: admin bisa mengganti petugas PIC dan semua pelanggan otomatis ikut ke petugas baru.

🧪 Testing — Feature Test
it('changing cluster petugas moves all pelanggan visibility', function () {
    $budi = petugasFactory(); $andi = petugasFactory();
    $cluster = Cluster::factory()->create(['officer_id' => $budi->id]);
    Customer::factory()->count(5)->create(['cluster_id' => $cluster->id]);

    // Sebelum: Budi lihat 5, Andi lihat 0
    $this->actingAs($budi);
    expect(Customer::count())->toBe(5);

    // Ganti PIC ke Andi
    $cluster->update(['officer_id' => $andi->id]);

    // Sesudah: Budi 0, Andi 5
    $this->actingAs($andi);
    expect(Customer::count())->toBe(5);
});
