📋 Konteks Bisnis Kunci (Ringkasan PRD v2.1)
  • Cluster = acuan penugasan pelanggan→petugas (bukan alamat). Alamat hanya referensi.
  • Paket = label referensi. default_price di-prefill ke transaksi tapi editable.
  • ISOLIR = jatuh tempo belum bayar → admin blokir manual → tetap ditagih → bayar → pulih aktif.
  • Alur uang 3-state: tunai di petugas → titip parsial ke admin → ATAU transfer langsung (settled, tanpa petugas).
  • Formula kunci: Uang di Petugas = Total Tunai − Total Disetor. Transfer TIDAK masuk.
  • Tanggal tagihan beda per pelanggan (1–31) dalam satu periode bulan.
